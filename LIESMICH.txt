REAKTIONSLABOR – WEB-APP
========================

Alle Dateien liegen absichtlich in EINEM Ordner (ohne Unterordner),
damit du sie am iPhone auf einmal hochladen kannst.

Online stellen mit GitHub Pages (kostenlos):
1. github.com > Konto anlegen > "+" > New repository
   Name z. B. labor, Public, Haken bei "Add a README file", Create repository
2. Add file > Upload files > choose your files > alle Dateien aus diesem
   Ordner auswählen > Commit changes
3. Settings > Pages > Source: "Deploy from a branch", Branch: main,
   Ordner: / (root) > Save
4. Nach 1–2 Minuten: https://DEINNAME.github.io/labor/

Am iPhone installieren:
Adresse in Safari öffnen > ••• > Teilen > "Zum Home-Bildschirm" >
"Als Web-App öffnen" eingeschaltet lassen > Hinzufügen.
Einmal mit Internet öffnen – danach läuft die App auch offline.

Spielstände liegen auf dem jeweiligen Gerät.
